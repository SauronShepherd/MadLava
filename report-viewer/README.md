# MadLava Report Viewer

Open `index.html` directly in a browser and choose a MadLava schema-v3 JSONL report. The viewer performs no network requests and renders report content through text-only DOM APIs.

The dashboard supports snapshot navigation, feature name/state filtering, health and diagnostic summaries, raw snapshot inspection, and a privacy-safe JSON summary export. Malformed lines and unsupported schema versions are rejected with their line number. No server, installation, cookies, telemetry, or external assets are used.
